# Захарова К.А. Шибаева Д.Д.
## МДК04.01 Практическая работа 2. Проектирование внедряемого ПО
### Тема: Электронный журнал группы

## 1. Постановка задачи

### Объект проектирования
Система электронного учёта успеваемости и посещаемости для колледжа.

### Проблемы
Ручное заполнение бумажных журналов
Дублирование и потеря данных
Трудоёмкий подсчёт баллов
Нет оперативного доступа родителей
Сложность контроля задолженностей

### Пользователи системы
Преподаватели
Студенты
Родители
Завуч и администрация

### Основные функции
Автоматический подсчёт баллов по предметам
Учёт посещаемости
Разграничение прав доступа
Система уведомлений
Формирование отчётов
Единая база данных

### Ожидаемый результат
Прозрачность учебного процесса
Снижение нагрузки на персонал
Быстрый доступ к отчётности
Минимизация ошибок

## 2. Выбор платформы реализации

### Выбранная платформа
Веб-платформа

### Критерии выбора
Доступ через браузер без установки
Централизованное обновление
Совместимость с инфраструктурой колледжа
Масштабируемость и безопасность

### Обоснование
Не требует установки на каждое рабочее место
Легко обновляется на сервере
Работает на любом устройстве
Подходит для всех ролей пользователей

## 3. Проектирование компонентов

### Схема компонентов
Пользователь -> Веб-интерфейс -> Сервер приложений -> База данных
Сервер приложений -> Модуль уведомлений
Сервер приложений -> Модуль отчётов

### Основные компоненты
Пользовательский интерфейс
Модуль авторизации
Модуль успеваемости
Модуль посещаемости
База данных
Модуль уведомлений
Модуль отчётности
